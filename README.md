# Squad — private Valorant friend hub

Minimal Discord-alternative for one closed friend group. Next.js + Supabase.

## Setup
1. `npm install`
2. Copy `.env.example` to `.env.local`, fill in your Supabase anon key
3. `npm run dev`

## Deploy
Import this repo on vercel.com, add the two env vars from `.env.example`, deploy.
Schema is already provisioned on the linked Supabase project.

See PRD.md for scope.
